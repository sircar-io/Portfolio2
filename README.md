# Siddhartha Sarkar — Creative Map

A one-page, editorial node map that explains where Siddhartha fits, what he can own, the business value of that range, and the verified work behind the claims.

## Narrative system

1. **SID / positioning** — Creative Strategist × Writer × Creative Generalist
2. **Capability branches** — Think / Make / Lead
3. **Ownership chain** — Brief → Idea → Script → Shoot → Edit → QC → Publish
4. **Business value** — fewer translation gaps, problem-level ownership, and tighter creative loops
5. **Role functions** — Creative Strategist, Content Lead, Creative Lead, Creative Generalist
6. **Selected work** — Ai+, Nothing / Death of PC, Zerodha / Hackonomics, South Indian Bank / The Fincredibles, and Brave Tech
7. **Proof** — verified creator performance and a visual evidence wall built from supplied work assets

## Visual system

- **Thesis:** an editorial creative operating-system map rather than a resume or corporate flowchart
- **Type:** expressive Georgia display typography with a compact system sans
- **Palette:** near-black, warm paper, acid lime, signal orange, and cool blue
- **Structure:** thin architectural connectors, restrained nodes, and a causal top-to-bottom reading order
- **Motion:** line drawing, scroll reveals, subtle parallax, and hover elevation
- **Responsive:** desktop branching becomes a legible vertical causal path on narrow screens
- **Accessibility:** semantic sections, keyboard navigation, alt text, logical source order, visible focus states, and reduced-motion support

## Content

Verified repeatable content lives in `lib/portfolio-content.ts`. Page structure and motion live in `app/portfolio.tsx`; styling and responsive behaviour live in `app/globals.css`. The evidence wall uses only the supplied assets in `public/assets/`.
